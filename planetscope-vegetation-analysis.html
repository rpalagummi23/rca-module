Extracting Bands with Python

Use rasterio to read PlanetScope Analytic Surface Reflectance (SR) GeoTIFF files.

import rasterio
import numpy as np

# Open PlanetScope analytic surface reflectance scene
with rasterio.open("planetscope_scene.tif") as src:
    coastal_blue = src.read(1).astype(float)
    blue         = src.read(2).astype(float)
    green_i      = src.read(3).astype(float)
    green        = src.read(4).astype(float)
    yellow       = src.read(5).astype(float)
    red          = src.read(6).astype(float)
    red_edge     = src.read(7).astype(float)
    nir          = src.read(8).astype(float)
    profile      = src.profile

Vegetation Indices

NDVI Most Common

Normalized Difference Vegetation Index. Standard measure of green vegetation density and health.

NDVI = (NIR − Red) / (NIR + Red)

Range: −1 to 1  |  Healthy vegetation: 0.3 – 0.8

ndvi = (nir - red) / (nir + red + 1e-10)

NDRE PlanetScope Advantage

Normalized Difference Red Edge. Sensitive to chlorophyll in mature canopies.

NDRE = (NIR − RedEdge) / (NIR + RedEdge)

Range: −1 to 1  |  Better for dense canopy

ndre = (nir - red_edge) / (nir + red_edge + 1e-10)

EVI High Biomass

Enhanced Vegetation Index. Reduces atmospheric and soil background noise.

EVI = 2.5 × (NIR − Red) / (NIR + 6×Red − 7.5×Blue + 1)

Range: −1 to 1  |  Best for dense forests

evi = 2.5 * (nir - red) / (nir + 6 * red - 7.5 * blue + 1)

SAVI Sparse Vegetation

Soil-Adjusted Vegetation Index. Minimizes soil brightness influence.

SAVI = ((NIR − Red) / (NIR + Red + L)) × (1 + L)

L = 0.5 (soil correction factor)

L = 0.5
savi = ((nir - red) / (nir + red + L)) * (1 + L)

Cloud Masking with UDM2

PlanetScope scenes include a UDM2 (Usable Data Mask) file with per-pixel quality flags. Always apply this before analysis.

# UDM2 bands: 1=clear, 2=snow, 3=shadow, 4=light haze, 5=heavy haze, 6=cloud, 7=confidence, 8=unusable
with rasterio.open("scene_udm2.tif") as udm:
    clear   = udm.read(1)   # 1 = clear pixel
    cloud   = udm.read(6)   # 1 = cloud pixel
    shadow  = udm.read(3)   # 1 = shadow pixel

# Create a clean mask: clear=1, no cloud, no shadow
clean_mask = (clear == 1) & (cloud == 0) & (shadow == 0)

# Apply mask to NDVI
ndvi_masked = np.where(clean_mask, ndvi, np.nan)

Visualization & Export

import matplotlib.pyplot as plt

# Plot NDVI
fig, ax = plt.subplots(figsize=(10, 10))
im = ax.imshow(ndvi_masked, cmap="RdYlGn", vmin=-0.2, vmax=0.8)
ax.set_title("NDVI - PlanetScope", fontsize=14)
plt.colorbar(im, ax=ax, label="NDVI", shrink=0.8)
ax.axis("off")
plt.tight_layout()
plt.show()

# Export NDVI as GeoTIFF
profile.update(dtype=rasterio.float32, count=1, nodata=np.nan)
with rasterio.open("ndvi_output.tif", "w", **profile) as dst:
    dst.write(ndvi_masked.astype(np.float32), 1)

Best Practices

Key Recommendations
  • Use Surface Reflectance (SR) products — atmospherically corrected and essential for accurate index values.
  • Always apply the UDM2 mask — exclude clouds, shadows, and haze before computing indices.
  • Leverage the Red Edge band (NDRE) — unique to PlanetScope and more sensitive than NDVI for dense/mature canopy stress detection.
  • For time-series analysis — normalize scenes using the same product type and account for BRDF effects.
  • Scale values — PlanetScope SR values may be scaled (e.g., 0–10000). Divide by 10000 to get 0–1 reflectance before computing indices.

Crop Growth Monitoring (Rice & Corn)

PlanetScope's daily revisit capability makes it ideal for tracking crop phenology from sowing through harvest. Below is a complete approach for monitoring rice and corn fields.

Data Acquisition Strategy

Capture imagery across the full growing season. Weekly cloud-free composites are more practical than daily scenes.

Crop Season Length Key Stages to Capture
Rice~120 – 150 daysTransplanting, Tillering, Heading, Grain fill, Harvest
Corn~90 – 130 daysEmergence, V6 (knee-high), Tasseling, Grain fill, Maturity
Product recommendation: Always use PSScene Analytic Surface Reflectance (SR) with the 8-band asset and UDM2 mask. Aim for imagery every 5–7 days.

Relevant Indices for Crop Monitoring

Index Formula What It Tells You
NDVI(NIR − Red) / (NIR + Red)Overall canopy greenness and biomass; tracks growth curve
NDRE(NIR − RedEdge) / (NIR + RedEdge)Chlorophyll content; stays sensitive when NDVI saturates at peak growth
NDMI(NIR − SWIR) / (NIR + SWIR)Canopy water content and moisture stress
EVI2.5 × (NIR − Red) / (NIR + 6R − 7.5B + 1)Biomass in dense canopy; less saturation than NDVI
SAVI((NIR − Red) / (NIR + Red + L)) × (1+L)Early season when soil is still visible
NDMI Note: PlanetScope does not have a SWIR band. Two options:
  • Proxy using Red Edge: (NIR − RedEdge) / (NIR + RedEdge) — correlates with canopy moisture to some degree (this is effectively NDRE)
  • Fuse with Sentinel-2 or Landsat SWIR: Use Sentinel-2 Band 11 (1610nm) or Landsat Band 6 for true NDMI, combined with PlanetScope for higher spatial resolution

Monitoring Workflow

  1. Define AOI (field boundary as GeoJSON / Shapefile)
  2. Order PlanetScope 8-band SR scenes covering the growing season
  3. For each scene:
    • Apply UDM2 cloud mask
    • Clip to AOI
    • Compute indices (NDVI, NDRE, EVI, SAVI)
    • Calculate field-average and per-pixel stats
  4. Build time-series dataframe (date, mean_ndvi, mean_ndre, …)
  5. Plot phenology curves
  6. Identify anomalies / stress events
  7. Compare against normal growth profiles

Stress Detection

Condition Signal
Water stressNDRE drops while NDVI stays high (early stress indicator)
Nutrient deficiencyLower NDVI plateau than healthy reference
Pest / diseaseLocalized NDVI drop within the field
Lodging (crop fell over)Sudden NDVI drop mid-season

PlanetScope Data Access Options

PlanetScope imagery requires a valid Planet account with data access. Below are the available pathways, including several free options for researchers.

Education & Research (E&R) Basic

Free
  • For university-affiliated researchers and students
  • 3,000 km²/month download quota
  • 30-day data delay (no real-time access)
  • Non-commercial use only
  • Apply at planet.com/markets/education-and-research

NASA CSDA (Commercial Smallsat Data Acquisition)

Free
  • For US federally-funded researchers
  • 5 million km² quota
  • PlanetScope + RapidEye archive
  • Full resolution, no delay
  • Apply via NASA Earthdata

ESA Network of Resources

Free
  • For researchers in ESA member states
  • PlanetScope + RapidEye + SkySat
  • Project-based quota allocation
  • Apply via ESA EO portal

DLR RESA (German Aerospace Center)

Free
  • For German researchers and institutions
  • PlanetScope + RapidEye + SkySat
  • Apply via DLR Earth Observation Center

Tropical Forest Observatory (NICFI)

Free
  • For nonprofits and researchers studying tropical forests
  • Monthly basemap mosaics over tropical regions
  • 4.77m resolution composites
  • Access via Planet NICFI portal

Commercial (Planet Monitoring)

Paid
  • Full API access with no delays or restrictions
  • Area-based subscription pricing
  • All product bundles including 8-band SR
  • Priority tasking and support available
  • Contact Planet sales for quotes
Recommendation: For academic crop monitoring research, start with E&R Basic (fastest approval). If you need real-time data or larger quotas, apply for NASA CSDA (US-funded) or ESA NoR (European). The 30-day delay on E&R Basic is usually acceptable for retrospective season analysis.
