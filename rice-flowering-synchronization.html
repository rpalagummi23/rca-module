Rice Male/Female Row Flowering Synchronization

Remote sensing approach for monitoring hybrid rice seed production using PlanetScope, UAV, and SAR data

1. What is Male/Female Row Synchronization?

In hybrid rice seed production, fields are planted with alternating rows of two distinct parent lines:

Female Parent (A-line / CMS)

Male-Sterile
  • Cytoplasmic Male Sterile (CMS) line — cannot produce viable pollen
  • Depends entirely on pollen from the male parent for seed set
  • Makes up the majority of the field (10–14 rows per block)
  • Shorter canopy, greener during anthesis

Male Parent (R-line / Restorer)

Fertile
  • Restorer line — provides fertile pollen
  • Carries genes that restore fertility in F1 hybrid offspring
  • Planted in narrow blocks (2 rows per block)
  • Taller canopy, yellowish during pollen shedding

Typical Field Layout

The standard planting configuration is 2R:10A to 2R:14A (2 male restorer rows for every 10–14 female CMS rows). Row orientation is typically east–west to ensure uniform sunlight interception and minimize shading of female panicles during morning anthesis.

Male block width: 2 rows × 20–30 cm spacing ≈ 40–60 cm
Female block width: 10–14 rows × 13–20 cm spacing ≈ 1.3–2.8 m
Full repeating unit: ≈ 1.7–3.4 m

Why Synchronization Matters

Flowering synchronization between the R-line and A-line is the single most critical factor for seed set percentage and hybrid seed yield. If the male sheds pollen when the female stigma is not receptive, seed set fails. Research shows:

  • Zero days difference in flowering between male and female → maximum seed yield (2.4–2.5 t/ha)
  • 2 days difference → moderate yield reduction
  • 5 days difference → significant yield loss
  • Flowering duration of the female line matters: a concentrated 5-day blooming burst (97% of florets open before noon) is ideal
  • GDD (Growing Degree Days) requirement difference between R-line and CMS line is typically ~210 degree-days — sowing dates must be staggered accordingly

2. Can PlanetScope Do This? — Honest Assessment

The Spatial Resolution Problem

Critical Limitation: PlanetScope is 3m per pixel. A single pixel covers the entire male+female block and then some. You cannot spatially distinguish male from female rows at 3m resolution.

Research that successfully separates male/female parents uses UAV imagery at 3–7 cm/pixel resolution — that is 50–100× finer than PlanetScope. UAV studies achieved 95.5% accuracy separating male/female parents using the ExGR (Excess Green minus Excess Red) index at centimeter resolution (MDPI Agriculture, 2022).

What PlanetScope CAN Do

PlanetScope’s strength is daily revisit at field level. It can track the temporal phenology of the entire seed production field as a unit:

Heading Date Detection

Feasible
  • NDVI reaches its maximum at heading/flowering
  • First derivative of smoothed NDVI changing from positive to negative = heading date
  • CIRedEdge detects booting stage (just before heading)
  • Accuracy: ~3–6 days for heading date estimation

Flowering Duration & Vigor

Feasible
  • Plateau width of NDVI near maximum indicates flowering duration
  • Sharp, narrow peak = synchronized flowering
  • Broad, flat peak = staggered flowering (risk)
  • NDRE avoids saturation at peak biomass

Stress During Reproductive Phase

Feasible
  • Sudden NDVI/NDRE drop during flowering window = stress event
  • Cold snap, heavy rain, or nutrient deficiency detected
  • Your existing Part 2 pipeline already handles this

Row-Level Male/Female ID

Not Feasible
  • Requires <10 cm resolution (UAV only)
  • Cannot identify which rows are male vs female at 3m
  • Cannot observe individual spikelet opening
  • Cannot measure stigma exsertion or anther traits

Key Spectral Indices

NDVI

Primary
NDVI = (NIR − Red) / (NIR + Red)

Maximum NDVI = heading date. First derivative sign change (positive → negative) marks the transition from vegetative to reproductive phase.

NDRE

Primary
NDRE = (NIR − RedEdge) / (NIR + RedEdge)

More sensitive than NDVI at peak biomass. Better differentiates “healthy dense” vs “very healthy dense” canopy during reproductive stage.

CIRedEdge

Booting Detection
CIRE = (NIR / RedEdge) − 1

Peaks at booting stage (just before heading). Accurately detects jointing and booting dates. Validated for rice phenology detection.

NDYI (Normalized Difference Yellow Index)

Experimental
NDYI = (Green − Blue) / (Green + Blue)

Originally used for rapeseed flowering detection. Potentially useful for detecting yellowish male anther emergence at field level, but untested for hybrid rice at satellite scale.

4. Getting Spatial Data from Your KML/AOI

Your KML file provides the field boundary polygon. The workflow to extract spatial data is:

  1. Parse KML → GeoJSON — your notebook cell 58 already does this using xml.etree.ElementTree
  2. Order PlanetScope scenes clipped to AOI — your Part 3 uses clip_tool(aoi=geometry) in the Orders API
  3. Load each scene and mask with UDM2 — your Part 1 applies the clear pixel mask
  4. Compute zonal statistics per date — extract mean NDVI, NDRE, CIRE within the AOI polygon for each cloud-free scene
  5. Build time-series — plot index values vs date to produce the phenology curve

from rasterio.mask import mask
import numpy as np
import json

# 1. Load AOI from GeoJSON (parsed from KML)
with open("field_boundary.geojson") as f:
    aoi = json.load(f)["geometry"]

# 2. For each scene date, extract clipped bands
with rasterio.open(scene_path) as src:
    clipped, transform = mask(src, [aoi], crop=True)
    nir  = clipped[7].astype("float32")  # Band 8 - NIR
    red  = clipped[5].astype("float32")  # Band 6 - Red
    re   = clipped[6].astype("float32")  # Band 7 - Red Edge

# 3. Compute indices (masked where valid)
ndvi = (nir - red) / (nir + red + 1e-10)
ndre = (nir - re)  / (nir + re  + 1e-10)
ci_re = (nir / (re + 1e-10)) - 1

# 4. Zonal mean for this date
mean_ndvi  = np.nanmean(ndvi[ndvi > 0])
mean_ndre  = np.nanmean(ndre[ndre > 0])
mean_ci_re = np.nanmean(ci_re[ci_re > 0])

5. Temporal Phenology Analysis for Synchronization

Since we cannot resolve individual rows, we use the temporal signature of the field to infer flowering timing and synchronization health.

Step-by-Step Approach

Step 1: Build the NDVI/NDRE Time-Series

From daily PlanetScope scenes (your Part 2 pipeline already does this). Apply UDM2 cloud masking to keep only clear pixels.

Step 2: Smooth with Savitzky-Golay or Double-Logistic Function

Removes noise, fills minor cloud gaps, produces a continuous curve. The smoothed curve shape encodes phenological information.

Step 4: Compare Against GDD-Predicted Heading Dates

Using known variety-specific GDD requirements and weather station temperature data:

GDDdaily = max(0, (Tmax + Tmin) / 2 − Tbase)
where Tbase = 10°C for rice
Accumulated GDD = Σ GDDdaily from sowing date to current date

Predicted heading date for each parent = date when accumulated GDD reaches variety-specific threshold. The GDD requirement of the restorer line is typically ~210 degree-days higher than the CMS line — sowing dates must be staggered to compensate.

Sync_gap = |Theading_predicted_R − Theading_predicted_A|

6. Flowering Synchronization Risk Index (FSRI)

A composite index to quantify synchronization health and predict yield risk. Combines phenological timing, canopy vigor, and stress events into a single actionable score.

FSRI Formula

FSRI = w1 × Heading_Deviation + w2 × Vigor_Asymmetry + w3 × Stress_Flag

Component 1: Heading Deviation

Heading_Deviation = |GDD_to_headingR − GDD_to_headingA| / target_GDD

Measures how far apart the predicted heading dates of male and female parents are, normalized by the target GDD. A value of 0 means perfect synchronization; values above 0.05 indicate risk.

Component 2: Vigor Asymmetry

Vigor_Asymmetry = 1 − (NDREat_heading / NDREmax_expected)

Whether the canopy is at expected vigor when heading occurs. Low vigor at heading suggests nutrient stress, water stress, or other conditions that impair flowering. A value of 0 means healthy; values above 0.2 are concerning.

Component 3: Stress Flag

Stress_Flag = max(0, NDVI_drop_during_flowering / NDVIat_heading)

Detects sudden NDVI drops during the flowering window, which indicate cold snaps, heavy rain, or other events disrupting anthesis. A value of 0 means stable conditions; values above 0.1 indicate a significant stress event.

Recommended Weights

w1 = 0.4     w2 = 0.3     w3 = 0.3

Weights should be calibrated with field-level seed set data from your specific region and varieties.

FSRI Interpretation Scale

FSRI < 0.1
Good Sync
FSRI 0.1 – 0.3
Moderate Risk
FSRI > 0.3
High Risk

FSRI < 0.1

Good synchronization expected. Heading dates align, canopy is vigorous, no stress events during flowering.

Action: Normal operations. No intervention needed.

FSRI 0.1 – 0.3

Moderate risk. Slight heading date mismatch, sub-optimal vigor, or a minor stress event detected.

Action: Consider supplementary pollination (GA3 application, rope pulling).

FSRI > 0.3

High risk of poor seed set. Significant heading mismatch, low canopy vigor, or major stress during flowering.

Action: Immediate intervention. Intensive supplementary pollination, adjust irrigation/nutrients.

7. Implementation: FSRI Computation

import numpy as np
from scipy.signal import savgol_filter
from datetime import datetime, timedelta

def compute_gdd(tmax_series, tmin_series, t_base=10.0):
    """Compute daily GDD from temperature arrays."""
    t_mean = (np.array(tmax_series) + np.array(tmin_series)) / 2.0
    gdd_daily = np.maximum(0, t_mean - t_base)
    return np.cumsum(gdd_daily)

def detect_heading_date(dates, ndvi_values, window=7):
    """Detect heading date as the date of maximum smoothed NDVI."""
    ndvi_smooth = savgol_filter(ndvi_values, window_length=window, polyorder=3)
    peak_idx = np.argmax(ndvi_smooth)
    return dates[peak_idx], ndvi_smooth[peak_idx], ndvi_smooth

def compute_fsri(
    gdd_heading_r, gdd_heading_a, target_gdd,
    ndre_at_heading, ndre_max_expected,
    ndvi_at_heading, ndvi_drop_during_flowering,
    w1=0.4, w2=0.3, w3=0.3
):
    """
    Compute the Flowering Synchronization Risk Index.

    Parameters
    ----------
    gdd_heading_r : float
        Accumulated GDD from R-line sowing to predicted heading.
    gdd_heading_a : float
        Accumulated GDD from A-line sowing to predicted heading.
    target_gdd : float
        Expected GDD for the variety (e.g., 1200 degree-days).
    ndre_at_heading : float
        Observed NDRE at the detected heading date.
    ndre_max_expected : float
        Expected NDRE for a healthy canopy at heading (from historical data).
    ndvi_at_heading : float
        NDVI at the detected heading date.
    ndvi_drop_during_flowering : float
        Maximum NDVI decrease observed during the flowering window
        (0 if NDVI was stable or increasing).

    Returns
    -------
    fsri : float
        Flowering Synchronization Risk Index (0 = best, >0.3 = high risk).
    components : dict
        Individual component values for diagnostics.
    """
    # Component 1: Heading deviation
    heading_dev = abs(gdd_heading_r - gdd_heading_a) / target_gdd

    # Component 2: Vigor asymmetry
    vigor_asym = max(0, 1.0 - (ndre_at_heading / (ndre_max_expected + 1e-10)))

    # Component 3: Stress flag
    stress_flag = max(0, ndvi_drop_during_flowering / (ndvi_at_heading + 1e-10))

    # Composite score
    fsri = w1 * heading_dev + w2 * vigor_asym + w3 * stress_flag

    components = {
        "heading_deviation": round(heading_dev, 4),
        "vigor_asymmetry": round(vigor_asym, 4),
        "stress_flag": round(stress_flag, 4),
        "fsri": round(fsri, 4),
    }
    return fsri, components

# ----- Example Usage -----
fsri, details = compute_fsri(
    gdd_heading_r=1250,       # R-line heading at 1250 GDD
    gdd_heading_a=1190,       # A-line heading at 1190 GDD
    target_gdd=1200,          # Variety target
    ndre_at_heading=0.42,     # Observed NDRE at heading
    ndre_max_expected=0.48,   # Historical healthy NDRE
    ndvi_at_heading=0.75,     # NDVI at heading
    ndvi_drop_during_flowering=0.03  # Minor drop
)
print(f"FSRI = {fsri:.3f}")
print(f"Components: {details}")
# Output: FSRI = 0.067  --  Good synchronization

8. SAR (Sentinel-1 VV/VH) for Cloud-Gap Filling

During monsoon season (critical for Kharif rice in Chhattisgarh), persistent cloud cover can create multi-week gaps in PlanetScope data. Sentinel-1 SAR sees through clouds and provides complementary phenology signals.

VH Backscatter & Rice Growth

  • Transplanting: VH minimum (flooded field, smooth water surface)
  • Tillering → Heading: VH rises steadily (increasing canopy volume scattering)
  • Heading/flowering: VH reaches maximum or plateau
  • Maturity: VH decreases (canopy drying, reduced water content)

Rice-Specific SAR Signatures

  • VH/VV ratio correlates with biomass, less affected by soil moisture
  • Rice-specific: Sharp VH dip at transplanting (flooded field) then rise through tillering — distinctive enough to detect rice fields from SAR alone
  • VH heading date ≈ optical heading date (± a few days)
  • C-band saturates for very tall/dense canopy late in season
SAR Preprocessing Required: Apply orbit file correction, thermal noise removal, radiometric calibration to σ0, and terrain correction (use ESA SNAP or s1tiling). Stick to one orbit track (ascending or descending) for time-series consistency, as backscatter varies with incidence angle.

13. Accuracy Assessment: How Reliable Is This Approach?

Q: How do you rate the accuracy of the male/female row synchronization with the approach outlined above?

Accuracy Rating by Component

ComponentRatingAccuracyRationale
Heading Date Detection Moderate-Good 70–80% Literature validates NDVI-maximum = heading date with 3–6 day accuracy using Sentinel-2 and MODIS. PlanetScope daily revisit should perform at least as well. However, 3–6 day uncertainty is significant when synchronization gaps of 2–5 days are what you are trying to detect. The signal you are measuring is the same order of magnitude as your measurement error.
GDD-Based Heading Prediction Good 75–85% GDD models for predicting heading are well-established in rice agronomy. Accuracy depends on having correct variety-specific GDD thresholds and accurate sowing dates. If you know the exact varieties and sowing dates, GDD prediction alone (without satellite) gives ~3 day accuracy. The satellite data essentially validates the GDD prediction, not replaces it.
Vigor Asymmetry (NDRE at heading) Low-Moderate 50–65% NDRE reflects the mixed signal of both male and female rows averaged together in every 3m pixel. Cannot separate whether low NDRE is from male rows, female rows, or both. It is a general canopy health indicator, not a synchronization-specific measurement.
Stress Flag (NDVI drop) Moderate 65–75% Detecting sudden NDVI drops is reliable with daily revisit. But the drop could be from clouds missed by UDM2, sensor noise, or non-flowering causes. Tells you “something bad happened during the flowering window” but not specifically “synchronization failed.”
FSRI Composite Score Low-Moderate 55–65% Composite of the above components. Useful as an early warning system but not reliable enough for precise synchronization assessment without calibration data.

Honest Assessment of Why Accuracy Is Limited

The FSRI formula is a reasonable conceptual framework, but it has not been validated. No published study has attempted to derive a flowering synchronization index from 3m satellite data for hybrid rice seed production fields.

The fundamental reasons:

  1. The synchronization signal is sub-pixel. The actual phenomenon (male anthers opening vs female stigma receptivity) happens at the centimeter scale. At 3m, you are averaging over both parent types in every pixel.
  2. The temporal precision needed (~1–2 days) pushes the limit of what phenology detection from satellite indices can achieve (3–6 day accuracy).
  3. The strongest component (heading deviation) comes from GDD models, not from the imagery. The satellite data adds incremental value by confirming/correcting the GDD prediction, but the heavy lifting is done by the agronomy model.
  4. No ground truth calibration exists. Without field-level seed set percentage data paired with satellite observations across multiple seasons, the weights (0.4, 0.3, 0.3) are educated guesses.

What Would Make This Accurate (80%+ Reliability)

  • 2–3 seasons of paired data: satellite time-series + field-recorded seed set percentages from the same fields
  • Known sowing dates and varieties for both A-line and R-line (you may already have this)
  • UAV validation flights during flowering to confirm row-level status on a subset of fields
  • Machine learning calibration of FSRI weights against actual seed set outcomes instead of the fixed 0.4 / 0.3 / 0.3

Practical Verdict

Recommendation: Use PlanetScope + GDD for coarse temporal monitoring and anomaly flagging across many fields, then deploy UAV flights to the flagged fields during the critical 5–7 day flowering window for the actual synchronization assessment. That two-tier approach would be genuinely actionable. The satellite alone, at its current 3m resolution, is not sufficient for confident synchronization scoring. To significantly improve satellite-only accuracy, move to very high resolution (VHR) satellites described in the next section.

Key Findings

  • No satellite below ~15 cm can confidently resolve individual male rows (40–60 cm). At 30 cm panchromatic, a male block is 1–2 pixels — detectable but not robust. UAVs at 3–7 cm remain the gold standard for row-level classification.
  • Pléiades Neo is the strongest single-satellite option because it combines 30 cm Pan with a Red Edge band — the only VHR satellite with this combination. This enables both spatial row detection (via panchromatic) and spectral flowering analysis (via NDRE) in a single acquisition.
  • WorldView Legion is the most promising for operational monitoring due to its 15×/day revisit and two Red Edge bands (695–715 nm and 730–750 nm), providing finer chlorophyll sensitivity than any competitor.
  • WorldView-3 offers a unique advantage with 8 SWIR bands at 3.7 m, enabling canopy water content and moisture analysis during flowering — relevant for detecting water stress that disrupts pollination.
  • SkySat at 50 cm is a step up from PlanetScope but the lack of Red Edge limits its value for flowering-specific analysis. Best used for spatial/textural analysis with NDVI only.
  • The optimal strategy combines PlanetScope (daily 3m temporal backbone, 8 bands) + a VHR satellite (30–50 cm targeted acquisitions during flowering) + UAV (cm-level validation on flagged fields).

Cost reality check: VHR satellite tasking is expensive. Pléiades Neo and WorldView imagery typically costs $10–25 per km² for new tasking, with minimum order sizes of 25–100 km². For small fields (<1 ha like your Chhattisgarh AOI), the per-field cost may exceed the value of the crop. VHR satellites become cost-effective when monitoring many fields simultaneously within a single acquisition footprint. For individual small fields, a UAV flight ($100–300 per flight) is far more cost-effective than a tasked VHR satellite acquisition.

15. Suggested Approach: Satellite-Only Strategy for Large-Scale Monitoring

UAV is the gold standard for row-level accuracy but is impractical across thousands of acres. The following satellite-only strategy maximizes accuracy while keeping costs manageable at scale.

15.1 Sensor Choice

Primary VHR: WorldView Legion or Pléiades Neo

  • 30 cm resolution, dual Red Edge bands (Legion) or Red Edge + 6 bands (Neo)
  • 15×/day revisit (Legion) maximizes chance of cloud-free capture during the critical 5–7 day flowering window
  • PlanetScope 3m as daily backup for temporal gap-filling

15.2 Core Approach: Dense Time-Series Phenology

  • Stack PlanetScope daily (3m) + VHR tasked passes (30 cm) during booting-to-flowering stage
  • Track per-field NDVI, NDRE, CIRedEdge curves separately
  • Detect heading date from NDVI peak / first-derivative zero-crossing (3–6 day accuracy)
  • Compare A-line vs R-line heading timing using GDD model calibrated to local variety

15.3 Where ML Adds Value (and Where It Doesn’t)

ML ApplicationRecommended?Details
Synchronization scoring Yes Random Forest or XGBoost trained on historical field-level outcomes (seed set %, yield) vs spectral time-series features (heading date gap, NDRE asymmetry, NDVI drop rate) — replaces hand-tuned FSRI weights with data-driven weights
Row pattern detection from VHR Yes CNN on VHR imagery to learn sub-pixel textural differences between male/female blocks (row pattern, canopy density contrast at 30 cm)
Phenology detection No Classical signal processing (Savitzky-Golay smoothing + zero-crossing) works better with sparse time-series than deep learning

15.4 Training Data Strategy (The Bottleneck)

Without ground truth, ML accuracy won’t exceed the 55–65% FSRI baseline.
  • Collect 2–3 seasons of ground truth: actual heading dates (A-line, R-line), seed set %, and GPS-tagged row locations for ~50–100 fields
  • Label each field as “synchronized” or “desynchronized” based on seed set outcome
  • This ground truth collection is the single biggest investment — but it is what separates a speculative index from a validated prediction model

15.6 Practical Workflow

  1. PlanetScope daily monitoring across all fields (cheap, broad coverage)
  2. Flag fields with abnormal NDVI/NDRE trajectories
  3. Task VHR satellite on flagged fields only (controls cost)
  4. ML model scores synchronization risk per field
  5. Ground-verify only high-risk flagged fields
Cost profile: ~$5–10/km² for PlanetScope blanket coverage + $15–25/km² for targeted VHR tasking on flagged fields only. This keeps total cost manageable while pushing accuracy toward 80–85% with sufficient training data.
