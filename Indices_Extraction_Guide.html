1. Executive Summary

This document outlines the process for extracting crop monitoring indices from European Space Agency (ESA) satellite data using the Copernicus Data Space Browser. The goal is to retrieve vegetation, moisture, thermal, and structural indicators for farm polygons defined by KML files.

Key Platform: Copernicus Data Space Browser
Data Sources: Sentinel-2 (Optical), Sentinel-3 (Thermal), Sentinel-1 (Radar - SAR)

Indices Overview

Category Indices Purpose
Vegetation NDVI, SAVI, MSAVI, NDRE, LAI Assess plant health and growth
Moisture NDMI Monitor water content in vegetation
Chlorophyll GCI Estimate chlorophyll concentration
Senescence PSRI Detect plant stress/aging
Thermal LST Land Surface Temperature

4. All Formulas Reference

All formulas below are standard scientific formulas readily available in remote sensing literature.

Vegetation Indices (Sentinel-2)

NDRE (Normalized Difference Red Edge)
= (NIR - RedEdge) / (NIR + RedEdge)
= (B08 - B05) / (B08 + B05)
GCI (Green Chlorophyll Index)
= (NIR / Green) - 1
= (B08 / B03) - 1
PSRI (Plant Senescence Reflectance Index)
= (Red - Green) / NIR
= (B04 - B03) / B08
MSAVI (Modified Soil Adjusted Vegetation Index)
= (2 * NIR + 1 - sqrt((2 * NIR + 1)^2 - 8 * (NIR - Red))) / 2
= (2 * B08 + 1 - sqrt((2 * B08 + 1)^2 - 8 * (B08 - B04))) / 2
EVI (Enhanced Vegetation Index) - Intermediate for LAI
= 2.5 * (NIR - Red) / (NIR + 6 * Red - 7.5 * Blue + 1)
= 2.5 * (B08 - B04) / (B08 + 6 * B04 - 7.5 * B02 + 1)
LAI (Leaf Area Index)
= 3.618 * EVI - 0.118
Note: Uses empirical EVI-based relationship

Thermal Index (Sentinel-3)

LST(K) - Land Surface Temperature in Kelvin
= T8 + 1.06 * (T8 - T9) + 0.46 * (T8 - T9)^2 + 54.3 * (1 - epsilon)

LST(C) - Convert to Celsius
= LST(K) - 273.15

Where:
- T8 = Brightness Temperature at S8 band (Kelvin)
- T9 = Brightness Temperature at S9 band (Kelvin)
- epsilon = Land surface emissivity (~0.97 for general land)

Algorithm: Sobrino et al. (2004) Split Window Algorithm
Formula Availability: All formulas are standard remote sensing indices available in scientific literature. The LAI formula uses an empirical relationship derived from EVI. The LST formula implements the Sobrino et al. (2004) Split Window Algorithm.

5. Step-by-Step Process

Phase 1: Prerequisites & Setup

  1. Create Copernicus Account
    Go to https://dataspace.copernicus.eu/ and register for a free account
  2. Prepare KML Files
    Create or obtain KML files defining your farm polygon boundaries (see Section 6 for sources)
  3. Set Up Spreadsheet
    Prepare Excel/Google Sheets with columns for all band values and formula calculations

Phase 2: Data Selection in Copernicus Browser

  1. Open Copernicus Browser
    Navigate to https://browser.dataspace.copernicus.eu/
  2. Upload KML File
    Use the upload/import polygon feature to load your farm boundary KML
  3. Select Dataset
    For vegetation indices: Choose Sentinel-2 Level-2A (Surface Reflectance)
    For LST: Choose Sentinel-3 SLSTR L1B
  4. Apply Filters
    Set cloud cover filter to ≤ 20%
    Select date/time window corresponding to crop stage (e.g., 30 DAS, 60 DAS)

Phase 3: Direct Index Retrieval (NDVI, SAVI, NDMI)

  1. Select Index Layer
    Go to Agriculture/Vegetation theme and select the desired index (NDVI, SAVI, or NDMI)
  2. Open Statistical Information
    Click on "Statistical Information" panel
  3. Record Mean Value
    Note the mean value displayed for your selected farm polygon
  4. Export Data
    Export or manually tabulate the values to your spreadsheet

Phase 4: Band Value Retrieval (for Calculated Indices)

  1. Open Spectral Explorer
    Navigate to "Spectral Explorer - Values" in the browser
  2. Retrieve Band Values
    Record mean reflectance values for: B02, B03, B04, B05, B08, B11
  3. Enter Values in Spreadsheet
    Input all band values into your prepared spreadsheet
  4. Apply Formulas
    Use the formulas from Section 4 to calculate MSAVI, NDRE, GCI, PSRI, and LAI

Phase 5: LST Calculation (Custom Script)

  1. Switch to Sentinel-3 SLSTR L1B
    Select Sentinel-3 SLSTR L1B dataset with cloud filter ≤ 20%
  2. Open Custom Script Editor
    Navigate to the custom script/EvalScript editor in the browser
  3. Paste LST Script
    Copy and paste the EvalScript provided in Section 7 of this document
  4. Run and Visualize
    Execute the script to generate the LST visualization map
  5. Extract Values
    Use statistical tools to extract mean LST values for your polygon

7. Custom EvalScripts for Copernicus Browser

LST (Land Surface Temperature) - Split Window Algorithm

Dataset: Sentinel-3 SLSTR L1B
Algorithm: Sobrino et al. (2004) Split Window

//VERSION=3 //LST (Land Surface Temperature) - Split Window Algorithm //Dataset: Sentinel-3 SLSTR L1B //Bands used: S8 (10.85 um) and S9 (12.0 um) - Brightness Temperature in Kelvin //Algorithm: Sobrino et al. (2004) Split Window //Color scale: Blue=0C, Green=20C, Yellow=35C, Red=50C+ function setup() { return { input: ["S8", "S9", "dataMask"], output: { bands: 4 } }; } function evaluatePixel(sample) { var T8 = sample.S8; // Brightness Temperature at S8 (10.85 um) in Kelvin var T9 = sample.S9; // Brightness Temperature at S9 (12.0 um) in Kelvin var epsilon = 0.97; // Fixed land emissivity var dT = T8 - T9; // Split window difference var LST_K = T8 + 1.06 * dT + 0.46 * dT * dT + 54.3 * (1 - epsilon); var LST_C = LST_K - 273.15; // Convert to Celsius // Color ramp: 0C=blue, 20C=green, 35C=yellow, 50C+=red var t = Math.max(0, Math.min(1, (LST_C - 0) / 50.0)); var r, g, b; if (t < 0.25) { r = 0; g = t * 4; b = 1; } else if (t < 0.5) { r = 0; g = 1; b = 1 - (t - 0.25) * 4; } else if (t < 0.75) { r = (t - 0.5) * 4; g = 1; b = 0; } else { r = 1; g = 1 - (t - 0.75) * 4; b = 0; } return [r, g, b, sample.dataMask]; }

LST Color Interpretation:

Color Temperature Range Typical Surface
Blue 0-20C (32-68F) Water bodies, reservoirs
Green 20-30C (68-86F) Vegetation, forests
Yellow 30-40C (86-104F) Mixed areas
Orange 40-45C (104-113F) Urban areas, bare soil
Red 45-50C+ (113F+) Hot surfaces, urban heat islands
